## 2. 裁决清单

### 2.1 桥接协议

- `[#A.001]` Python 只通过一个 `js_api` 对象 `Bridge` 暴露一个公开方法 `rpc(envelopeJson) -> responseJson`。其余成员全部下划线私有，避免 pywebview 递归暴露。
- `[#A.002]` 请求信封：`{ v:1, id, cmd, params, timeoutMs }`；响应信封：`{ v:1, id, ok, result?, error?, meta:{ durationMs, ts } }`。
- `[#A.003]` 后端 `rpc` 永不向 js_api 抛异常；参数/命令/内部错误全部编码进 `error`。
- `[#A.004]` 超时由前端计时器强制执行；`timeoutMs` 仅作后端参考，后端 clamp 到 `500..60000ms`，不做中断。
- `[#A.005]` 事件推送：后端 `evaluate_js` 调用 `window.__SLATE_EVENTS__.receive("<json>")`；事件信封 `{ v:1, type:'event', event, seq, ts, data }`。事件不重放，前端容忍 seq 跳号。
- `[#A.006]` `id` 由前端生成，优先 `crypto.randomUUID()`；迟到响应按 id 丢弃。
- `[#A.007]` JSON 字段统一 camelCase；命令名使用 `domain.action`（如 `window.toggleMaximize`）。
- `[#A.008]` 命令登记表 `CommandMap` 在 `frontend/src/bridge/protocol.ts` 冻结；新增命令必须升契约版本。
- `[#A.009]` 错误码封闭集合：`E_BAD_ENVELOPE | E_UNKNOWN_CMD | E_INVALID_PARAMS | E_TIMEOUT | E_UNAVAILABLE | E_CANCELLED | E_INTERNAL | E_DEMO`。

已冻结命令：

| 命令 | 参数 | 返回 |
|---|---|---|
| `bridge.hello` | `{ client, protocol }` | `{ server, protocol, pid, startedAt }` |
| `system.info` | `{}` | `SystemInfo` |
| `system.echo` | `{ text, delayMs? }` | `{ text, delayMs }` |
| `demo.fail` | `{ message? }` | 失败，`E_DEMO` |
| `demo.slow` | `{ delayMs }` | `{ delayMs }` |
| `window.minimize` | `{}` | `{ state }` |
| `window.toggleMaximize` | `{}` | `WindowSnapshot` |
| `window.close` | `{}` | `{ closed }` |
| `window.state` | `{}` | `WindowSnapshot` |
| `config.get` | `{}` | `{ ui, window }` |
| `config.patchUi` | `Partial<UiState>` | `UiState` |

已冻结事件：

| 事件 | 数据 |
|---|---|
| `bridge.ready` | `{ protocol, server }` |
| `system.tick` | `{ seq, uptimeMs }` |
| `window.state` | `WindowSnapshot` |
| `config.changed` | `{ ui }` |

### 2.2 控件契约

- `[#A.010]` 所有控件是工厂函数：`createXxx(options) -> XxxHandle`；handle 至少含 `el` 与 `destroy()`；禁止全局单例。
- `[#A.011]` 基础尺寸 `sm|md|lg`；按钮变体 `primary|secondary|ghost|danger`。基础按钮/图标按钮由奠基层提供，轨道只消费。
- `[#A.012]` UI 核心工具（DOM 构建、事件总线、焦点陷阱）由奠基层提供；禁止 `innerHTML` 注入动态内容。

### 2.3 UI 基础设施与视觉

- `[#A.013]` 弹窗/浮层统一走 `ui/core/overlay.ts`：模态带遮罩 + 焦点陷阱 + ESC；锚定浮层自动翻转。
- `[#A.014]` 原生滚动条全局隐藏；所有滚动区域使用 `createScrollArea()`，支持 y/x/both、拖拽、点击翻页、自动显隐。
- `[#A.015]` 图标仅使用 `ui/icons/index.ts` 内联 SVG 路径；新增图标由仲裁者统一追加。
- `[#A.016]` 应用外壳固定为：标题栏 / 侧边导航 / 页面头 / 内容出口 / 状态栏。页面模块契约：
  ```ts
  export interface PageModule {
    id: 'form' | 'structure' | 'system';
    label: string;
    icon: IconName;
    description: string;
    render(): HTMLElement;
  }
  ```
  路由 id 固定为 `form`、`structure`、`system`，不得新增或改名。
- `[#A.017]` 标题栏拖拽区使用 `.pywebview-drag-region`；窗口命令只走 `bridge.call`；双击拖拽区切换最大化。
- `[#A.020]` 设计令牌唯一源 `frontend/src/styles/tokens.css`；组件 CSS 不得写死颜色/字号/间距/圆角/时值。亮/暗两套主题通过 `data-theme` 切换。
- `[#A.021]` 全局禁用右键菜单与文本选中；仅 `input / textarea / [contenteditable]` 放行文本选择。

### 2.4 配置与窗口状态

- `[#A.030]` 配置目录固定为项目根 `config/`：
  - `config/app.config.json`：初始化配置，应用只读，不写回。
  - `config/runtime/ui-state.json`：UI 运行时状态，`{ theme, density }`。
  - `config/runtime/window-state.json`：窗口几何与最大化状态（T-C 实现）。
  - 读写必须原子替换（临时文件 + `os.replace`），UTF-8、两空格缩进。
- `[#A.031]` 窗口状态文件格式：
  ```json
  {
    "version": 1,
    "state": "normal",
    "bounds": { "x": 120, "y": 90, "width": 1180, "height": 780 }
  }
  ```
  保存时机：`moved`/`resized` 去抖 400ms、最大化/还原、关闭前；恢复时夹紧到最小尺寸，若完全落在屏幕外则居中。
- `[#A.032]` 配置损坏时写 `.bak` 并用默认值继续启动，不允许阻塞启动。
