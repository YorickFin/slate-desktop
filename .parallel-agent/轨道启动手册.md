## 1. 启动话术

仲裁者通过编排器发送固定话术（不含任务内容）：

```
读 .parallel-agent/轨道启动手册.md 与 .parallel-agent/契约块.md，你是 T-X，待命。
```

轨道启动后必须：

1. 读本手册与契约块；
2. 检查自己的文件领地；
3. 写 `就绪/T-X.md`，内容为：已读版本、契约版本、当前状态“待命”；
4. 等待 `转达/第N轮/T-X-vM.md` 出现后再开工。**启动阶段禁止提前读转达单**。

## 2. 项目速览

| 层 | 技术 | 入口 |
|---|---|---|
| 壳 | pywebview frameless | `backend/main.py` |
| 后端 | Python 3.12 + 单 `Bridge.rpc` | `backend/app/bridge.py` |
| 前端 | Vite 7 + TS 5.9 + 原生 DOM | `frontend/src/main.ts` |
| 视觉 | CSS 变量设计令牌 | `frontend/src/styles/tokens.css` |
| 配置 | 项目 `config/` | `config/app.config.json`、`config/runtime/` |

常用命令：

```powershell
# 后端依赖（项目级 venv）
uv sync

# 前端依赖
cd frontend
pnpm install

# 类型检查 / 构建
pnpm typecheck
pnpm build

# 开发模式（两个终端）
cd frontend; pnpm dev
uv run python backend/main.py --dev

# 生产模式
uv run python backend/main.py
```

## 3. 轨道与领地

### T-A2 · 表单控件（职责 T-A）

**职责**：自绘 Input / Textarea / Select / Checkbox / RadioGroup / Switch / Slider，以及表单控件演示页。

**只写**：

```
frontend/src/ui/controls/form/**
frontend/src/app/pages/form-controls.ts
```

**验收**：
- 7 个控件全部可用，鼠标 + 键盘（Tab/方向键/空格/Enter）可操作；
- 无任何系统原生外观；焦点环、禁用态、错误态齐全；
- 亮/暗主题下均使用令牌，无写死颜色；
- `pnpm typecheck` 通过；页面在 `--dev` 与生产构建中均正常。

### T-B2 · 结构/反馈控件（职责 T-B）

**职责**：自绘 Tabs / Dialog / Toast / Table，以及结构控件演示页。

**只写**：

```
frontend/src/ui/controls/structure/**
frontend/src/app/pages/structure-controls.ts
```

**验收**：
- Tabs 支持键盘左右切换与 `aria-selected`；
- Dialog 必须复用 `ui/core/overlay.ts`，具备焦点陷阱、ESC、遮罩关闭；
- Toast 支持堆叠、自动消失、手动关闭、四种 tone；
- Table 支持表头/行/选中态/空态，滚动必须使用 `createScrollArea()`；
- `pnpm typecheck` 通过。

### T-C2 · 壳、桥与运行状态（职责 T-C）

**职责**：窗口状态记忆、配置持久化、标题栏补全、系统状态页；后端命令实现与协议健壮性。

**只写**：

```
backend/**
frontend/src/app/titlebar.ts
frontend/src/app/titlebar.css
frontend/src/app/pages/system.ts
config/runtime/**（运行时产物）
```

**验收**：
- 关闭再启动后窗口位置/尺寸/最大化状态恢复；
- 标题栏最小化/最大化/关闭可用，图标随状态切换；
- 系统页展示 `system.info`、桥接状态、事件计数、窗口几何；
- 主题/密度切换写入 `config/runtime/ui-state.json` 并即时生效；
- `uv run python backend/main.py` 可启动，`pnpm typecheck` 通过。

## 4. 铁律

1. **只写自己领地**。冻结文件只读；需要改动时在回执写“越界申请”，由仲裁者代改。
2. **不新增公开 js_api 方法**。所有后端能力通过 `Bridge._register(cmd, handler)` 注册。
3. **不引入依赖**。前端不得新增任何 UI/状态/工具库；确需新增依赖先申请。
4. **不写死视觉值**。颜色、字号、间距、圆角、动效一律引用 `tokens.css`。
5. **不使用原生外观**。禁止 `<select>`、原生 checkbox/radio、原生滚动条、原生 alert/confirm。
6. **不改契约**。发现签名不足，写“契约变更申请”，由仲裁者升版本后统一改。
7. **验证后交付**。回执必须附命令与结果；跨轨类型错误只报告，不代修。

## 5. 回执格式

写入 `回执/第N轮/T-X-vM.md`：

```markdown
# 回执 · 第N轮 · T-X-vM

## 结论
完成 / 部分完成 / 阻塞（一句话）

## 改动清单
- path/to/file.ts（+120 / -8）
- ...

## 证据
- 命令：`pnpm typecheck` → 通过
- 命令：`pnpm build` → 通过
- 页面/交互：...（说明或截图路径）

## 自检
- 错误率：x%（工具调用失败 y / 总 z）
- 健康度：良好 / 注意 / 警告
- 建议：继续 / 需要契约变更 / 需要仲裁

## 越界声明
无 / 申请：...（原因 + 期望 diff）
```

文件出现即视为完成信号；不要修改历史版本回执。
